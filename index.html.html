System Capabilities

Everything the Establishment Unit Needs

The system addresses the critical shortcomings of the manual attendance process, including falsification, delays in reporting, and data loss.

Digital Clock-In / Clock-Out

Employees record their arrival and departure times electronically, eliminating manual time entries and paper registers.

Anti-Buddy Punching

Each employee has unique login credentials. The system prevents one staff member from signing in on behalf of another.

Automated Reports

Generate daily, weekly, and monthly attendance summaries in minutes. Export reports for payroll and performance evaluation.

Lateness & Absence Tracking

Immediately detect patterns of lateness and absenteeism. Administrators receive real-time visibility of staff presence.

Role-Based Access Control

Separate dashboards for administrators and staff. Administrators manage employees, reports, and system settings.

Secure Data Storage

All attendance records are stored in a relational database, protected against loss, damage, and tampering.

The management of employee attendance in many Nigerian polytechnic establishments relies heavily on manual paper-based processes, which are susceptible to inaccuracies, time theft, and administrative inefficiencies. This project presents the design and implementation of an Employee Clocking System for the Establishment Unit of Plateau State Polytechnic, Barkin Ladi. The study identifies the critical shortcomings of the existing manual clocking approach, including falsification of attendance records, inability to generate timely reports, and difficulty in monitoring lateness and absenteeism. The proposed system was developed using Python, the Django web framework, SQLite/MySQL, and HTML/CSS/JavaScript, all deployed on a local network server environment.

The Establishment Unit currently operates a manual attendance recording system that is inadequate for the institution's growing administrative demands. Key problems include: falsification of attendance records through buddy punching, inefficiency in report generation causing delays in payroll computation, data loss and damage due to paper vulnerabilities, difficulty in monitoring lateness and absenteeism, and a high administrative burden on records staff.

Aim: To design and implement a web-based Employee Clocking System for the Establishment Unit of Plateau State Polytechnic, Barkin Ladi, to improve the accuracy and efficiency of staff attendance management.

Objectives:
  • To analyse the existing manual attendance system and identify its weaknesses.
  • To design a database-driven system capable of recording clock-in and clock-out times electronically.
  • To develop an administrative dashboard for real-time monitoring of staff punctuality.
  • To implement automated report generation for daily, weekly, and monthly attendance summaries.

The system follows the Model-View-Template (MVT) architecture, as implemented by Django. The database schema comprises two core entities: Employee (with a one-to-one reference to Django's built-in User model) and Attendance (storing clock-in time, clock-out time, date, and status). The Entity Relationship Diagram (ERD) illustrates a one-to-many relationship: one employee can have many attendance records. Data flow diagrams (context-level and level 1) document the interaction between employees, the system, and administrators.

The system was implemented using Python and Django, with SQLite for development and MySQL for production. Key features include secure user authentication, clock-in/clock-out logic with duplicate prevention, an administrative dashboard, and report generation. Black-box testing was conducted across 10 test cases covering valid login, invalid login, clock-in, duplicate clock-in, clock-out, clock-out without clock-in, report generation, employee management, and blank form submission. All 10 test cases passed successfully.

Clock-In Logic (views.py): 
@login_required
def clock_in(request):
    employee = request.user.employee
    today = timezone.now().date()
    if Attendance.objects.filter(employee=employee, attendance_date=today).exists():
        return HttpResponse("You have already clocked in today.")
    Attendance.objects.create(
        employee=employee,
        clock_in_time=timezone.now(),
        attendance_date=today,
        status='present'
    )
    return HttpResponse("Clock-in successful!")
